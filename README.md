# Fragments by E2B

This is an open-source version of apps like [Anthropic's Claude Artifacts](https://www.anthropic.com/news/claude-3-5-sonnet), Vercel [v0](https://v0.dev), or [GPT Engineer](https://gptengineer.app).

Powered by the [E2B SDK](https://github.com/e2b-dev/code-interpreter).

[→ Try on fragments.e2b.dev](https://fragments.e2b.dev)

## Features

- Based on Next.js 14 (App Router, Server Actions), shadcn/ui, TailwindCSS, Vercel AI SDK.
- Uses the [E2B SDK](https://github.com/e2b-dev/code-interpreter) by [E2B](https://e2b.dev) to securely execute code generated by AI.
- Streaming in the UI.
- Can install and use any package from npm, pip.
- Supported stacks ([build your own templates](#building-sandbox-templates)):
  - 🔸 Python interpreter
  - 🔸 Next.js
  - 🔸 Vue.js
  - 🔸 Streamlit
  - 🔸 Gradio
- Supported LLM Providers ([add your own](#adding-custom-llm-models)):
  - 🔸 OpenAI
  - 🔸 Anthropic
  - 🔸 Google AI
  - 🔸 Mistral
  - 🔸 Groq
  - 🔸 Fireworks
  - 🔸 Together AI
  - 🔸 Ollama
- Integrates with [Morph](https://morphllm.com/) Apply model for token efficient, accurate and faster code editing.

## Get started

### Prerequisites

- [git](https://git-scm.com)
- Recent version of [Node.js](https://nodejs.org) and npm package manager
- [E2B API Key](https://e2b.dev)
- LLM Provider API Key

### 1. Clone the repository

In your terminal:

```
git clone https://github.com/e2b-dev/fragments.git
```

### 2. Install the dependencies

Enter the repository:

```
cd fragments
```

Run the following to install the required dependencies:

```
npm i
```

### 3. Set the environment variables

Create a `.env.local` file and set the following:

```sh
# Get your API key here - https://e2b.dev/
E2B_API_KEY="your-e2b-api-key"

# Unique prefix for your E2B templates (e.g., your GitHub username)
# This prevents naming conflicts since E2B template names are globally unique
E2B_TEMPLATE_PREFIX="your-username"

# OpenAI API Key
OPENAI_API_KEY=

# Other providers
ANTHROPIC_API_KEY=
GROQ_API_KEY=
FIREWORKS_API_KEY=
TOGETHER_API_KEY=
GOOGLE_AI_API_KEY=
GOOGLE_VERTEX_CREDENTIALS=
MISTRAL_API_KEY=
XAI_API_KEY=

### Optional env vars

# (on by default) Get your MORPH key here - https://morphllm.com/dashboard/api-keys
MORPH_API_KEY=

# Domain of the site
NEXT_PUBLIC_SITE_URL=

# Rate limit
RATE_LIMIT_MAX_REQUESTS=
RATE_LIMIT_WINDOW=

# Vercel/Upstash KV (short URLs, rate limiting)
KV_REST_API_URL=
KV_REST_API_TOKEN=

# Supabase (auth)
SUPABASE_URL=
SUPABASE_ANON_KEY=

# PostHog (analytics)
NEXT_PUBLIC_POSTHOG_KEY=
NEXT_PUBLIC_POSTHOG_HOST=

### Disabling functionality (when uncommented)

# Disable API key and base URL input in the chat
# NEXT_PUBLIC_NO_API_KEY_INPUT=
# NEXT_PUBLIC_NO_BASE_URL_INPUT=

# Hide local models from the list of available models
# NEXT_PUBLIC_HIDE_LOCAL_MODELS=
```

### 4. Build the sandbox templates

Build all E2B sandbox templates (required before running the app):

```
npm run build:templates -- --prefix=your-username
```

Replace `your-username` with a unique identifier (e.g., your GitHub username). This prevents naming conflicts since E2B template names are globally unique.

This will build all templates in development mode. See [Building sandbox templates](#building-sandbox-templates) for more details.

### 5. Start the development server

```
npm run dev
```

### 6. Build the web app

```
npm run build
```

## Customize

### Building sandbox templates

Fragments uses [E2B sandboxes](https://e2b.dev) for secure code execution. You need to build the sandbox templates under your own E2B account before using them.

#### Prerequisites

1. Make sure you have an [E2B account](https://e2b.dev) and your API key is set in `.env.local`
2. Install dependencies in the root directory:
   ```
   npm install
   ```

#### Building the example templates

The repository includes example templates in [sandbox-templates/](sandbox-templates/).

**Quick start - Build all templates at once:**

From the root directory, run:
```
npm run build:templates -- --prefix=your-username
```

Replace `your-username` with a unique identifier (e.g., your GitHub username). This prevents naming conflicts with other users since E2B template names are globally unique.

This will automatically build all templates in development mode (with `-dev` suffix). For production builds:
```
npm run build:templates:prod -- --prefix=your-username
```

The prefix is optional but highly recommended to avoid conflicts.

**Manual build - Build templates individually:**

If you prefer to build templates one at a time:

1. Navigate to a template directory:
   ```
   cd sandbox-templates/nextjs-developer
   ```

2. Install the template dependencies:
   ```
   npm install
   ```

3. Build the template for development (with `-dev` suffix):
   ```
   npm run build:dev
   ```

   Or for production:
   ```
   npm run build:prod
   ```

4. Repeat for other templates (vue-developer, streamlit-developer, gradio-developer)

**Note:** The Python interpreter (`code-interpreter-v1`) is a pre-built E2B template and doesn't need to be built.

#### Creating custom templates

**Quick start - Use the template generator:**

From the root directory, run:
```
npm run create:template
```

This interactive script will:
1. Ask for your template name, base image (Node.js or Python), port, and other details
2. Generate all the necessary boilerplate files
3. Show you the next steps to get the template running
4. Optionally, add a logo under [public/thirdparty/templates](public/thirdparty/templates)

For more information on the Template API, see the [E2B Template documentation](https://e2b.dev/docs/template/defining-template)

### Adding custom LLM models

1. Open [lib/models.json](lib/models.ts) in your code editor.

2. Add a new entry to the models list:

    ```json
    {
      "id": "mistral-large",
      "name": "Mistral Large",
      "provider": "Ollama",
      "providerId": "ollama"
    }
    ```

    Where id is the model id, name is the model name (visible in the UI), provider is the provider name and providerId is the provider tag (see [adding providers](#adding-custom-llm-providers) below).

### Adding custom LLM providers

1. Open [lib/models.ts](lib/models.ts) in your code editor.

2. Add a new entry to the `providerConfigs` list:

    Example for fireworks:

    ```ts
    fireworks: () => createOpenAI({ apiKey: apiKey || process.env.FIREWORKS_API_KEY, baseURL: baseURL || 'https://api.fireworks.ai/inference/v1' })(modelNameString),
    ```

3. Optionally, adjust the default structured output mode in the `getDefaultMode` function:

    ```ts
    if (providerId === 'fireworks') {
      return 'json'
    }
    ```

4. Optionally, add a new logo under [public/thirdparty/logos](public/thirdparty/logos)
